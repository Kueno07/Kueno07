# Data & Analytics

I work with data governance, master data and analytics, including Databricks and Microsoft Power BI. I lead a data team.

## Data and analytics

**[catalog-quality-deduplication](https://github.com/Kueno07/catalog-quality-deduplication)**: a Python script that flags catalog records with different product IDs but matching normalized attributes.

**[consumer-campaign-analysis](https://github.com/Kueno07/consumer-campaign-analysis)**: SQL for comparing campaign outcomes between randomized treatment and control groups.

**[marketplace-operations-analysis](https://github.com/Kueno07/marketplace-operations-analysis)**: SQL that keeps order cancellation, unit fill rate and product-line availability as separate metrics.

## Engineering

**[study-game-engine](https://github.com/Kueno07/study-game-engine)**: serverless backend for a study game using Vercel and Upstash Redis. It includes separate preview and production data, phrase-based login, spaced review, tests, CI and secret scanning.

**[agente-biografico](https://github.com/Kueno07/agente-biografico)**: single-file web app for guided memoir creation as a DOCX. No backend. [Live version](https://kueno07.github.io/agente-biografico/).

**[cdmp-study-agent](https://github.com/Kueno07/cdmp-study-agent)**: adaptive practice-question skill for the CDMP (DAMA) exam.
